# Superseded plans and dated research

These files preserve earlier reasoning and requirements. They are not current execution instructions, status ledgers, or fresh-clone setup guides.

- `workbench-plan-2026-10-20.md` preserves the former 195-item handoff unchanged.
- `legacy-milestone-map.tsv` maps every old ID to surviving ownership or deferred scope. Mapping does not imply acceptance.
- `milestones-before-cleanup.tsv` preserves the prior 21-gate ledger before consolidation.
- `manifest.json` records the archived files' hashes.

The single editable ledger is [docs/milestones.tsv](../milestones.tsv). Its [generated view](../roadmap.md) is the current queue. Dated evidence lives under [reports/research](../../reports/research/README.md).

Older duplicate plans, before/after snapshots, and verbose diagnostic logs remain in ignored local planning history. Their [hash catalog](../../reports/research/local-history-catalog.json) preserves provenance without publishing several copies of the same plan.

MakerMods UI, direct agents, local VLA optimizer/GPU machinery, inference IK, food/portion physics, fixed six-joint completion, and future wrists/scoop are deferred. Revisit only when a selected task or actual build requires them. Shared control, cameras, recording, loaded-joint checks, and measured outcomes remain required.
